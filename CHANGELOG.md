# История версий

## Как это устроено

**Одна версия — один выкат на сервер.** Патч (`0.1.1` → `0.1.2`) растёт при
каждом деплое. Коммиты между деплоями версии не получают: если код не на
сервере, отдельной версии у него нет — он копится в следующую.

- **Патч** `0.1.x` — очередной выкат: новые возможности, исправления, что угодно.
- **Минор** `0.2.0` — меняется то, **как люди работают**: появляется роль,
  переделывается кабинет, ломается привычный порядок действий.
- **Мажор** `1.0.0` — выполнен критерий готовности v1 из `PASSPORT.md`.

Версия видна **в шапке приложения справа**. Можно открыть сервер и убедиться,
что обновление доехало, не залезая в консоль.

### Порядок выката

```bash
# 1. Поднять версию в package.json, дописать раздел сюда, закоммитить
git tag -a v0.1.2 -m "коротко о выкате"
git push origin claude/company-app-project-xxhilu --tags

# 2. Выкатить
cd /opt/guildofcomfort
git pull origin claude/company-app-project-xxhilu
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml run --rm migrate

# 3. Открыть сайт и сверить версию в шапке с тем, что ставили
```

Тег ставится **до** выката, а раздел здесь помечается «выкачено» только
после того, как версия в шапке сошлась.

## Оговорка о том, что было раньше

**До 15.08.2026 версии не проставлялись.** Ни тегов, ни записей о выкатах не
осталось: `package.json` всё это время стоял на дефолтном `0.1.0` от
генератора проекта, а на работающем сервере не было способа узнать, какой код
там развёрнут.

Восстановить «какая версия принята на каждом деплое» по истории **нельзя** —
её никто не записывал. Достоверно известно только одно: деплой на
`158.255.0.71` состоялся около 6 августа. На 12 августа контейнеры были
подняты шесть суток, а выгрузка табеля в Excel от 10 августа туда не попала.
Более ранние выкаты, возможно, были — следов не осталось.

Поэтому ниже всего две записи, и обе честные: то, что крутится на сервере
сейчас, и всё, что с тех пор накопилось в ветке.

## 0.1.1 — готово, не выкачено

Девять дней работы, которые на сервер ещё не уезжали. Выкатывается одним
разом, поэтому и версия одна.

**Работа по коммерческому предложению**

- Загрузка книги `.xlsx` прямо с телефона: дерево задач, веса, блоки работ
  и очерёдность заводятся за один раз — 92 строки вместо ручного ввода
- Готовность считается по **стоимости позиций КП**, а не по числу закрытых
  строк: прокладка кабеля за 84 000 ₽ весит 36,3 % объекта
- Иерархия задач: раздел → задача → подзадача → под-подзадача
- Блоки работ с графом очерёдности, порогом готовности предшественников
  и ручной причиной блокировки
- Гибкие задачи: монтажник сам заводит подзадачи с участком и объёмом

**Учёт работ**

- Нормирование техкарты на единицу объёма и трудозатраты
- Выгрузка табеля в Excel по образцу таблицы компании
- Правка и удаление записей табеля

**Люди и объекты**

- Увольнение сотрудника: доступ закрывается при первом же обращении,
  а не через неделю, когда истечёт токен
- Возврат уволенного и удаление тех, кто ничего не успел сделать
- Удаление объекта со всем содержимым

**Доступ**

- Восстановление пароля по ссылке на почту, срок 24 часа
- Письма через свой SMTP, все отправки пишутся в журнал

**Прочее**

- Загрузка картинок оформления с телефона в том Docker
- Версия приложения видна в шапке
- Схема базы данных отдельной HTML-страницей
- Исправлена инструкция обновления в `DEPLOY.md`: раньше там был голый
  `git pull` без каталога и без имени ветки

**Требует миграций: четыре.** Отключение пользователя · почта · дерево задач
с весами · блоки работ и деньги КП.

## 0.1.0 — выкачено ~06.08.2026

То, что сейчас развёрнуто на `158.255.0.71`. Номер присвоен задним числом
15 августа: на момент выката версий не было.

- Объекты → подпроекты → задачи по справочнику операций с техкартами
- Складской учёт материалов по объектам
- Табель монтажников, мобильный экран и роль бригадира
- Приватные взаиморасчёты
- Три роли с раздельными кабинетами: администратор, монтажник, заказчик
- Своя аутентификация: bcrypt + JWT в httpOnly-cookie
- Развёртывание через Docker Compose, скрипт деплоя на VPS
- Продуктовая документация: 44 истории, 13 сценариев, карта историй, вики

Версия в шапке у неё **не отображается** — механизма тогда не было. Если
в шапке пусто, значит на сервере всё ещё 0.1.0.
